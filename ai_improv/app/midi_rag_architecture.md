# MIDI RAG 시스템 아키텍처 설계

## 1. 시스템 개요

MIDI RAG(Retrieval-Augmented Generation) 시스템은 MCP, LangChain, FastAPI, YuE를 활용하여 MIDI 파일을 기반으로 한 AI 즉흥 연주 프로그램을 구현합니다. 이 시스템은 사용자가 입력한 MIDI 파일과 유사한 특성을 가진 MIDI 파일을 검색하고, 이를 기반으로 새로운 MIDI 음악을 생성합니다.

## 2. 아키텍처 구성 요소

### 2.1 데이터 처리 및 저장 계층

#### MIDI 특징 추출기 (MIDIFeatureExtractor)
- 기존 코드의 `MIDIFeatureExtractor` 클래스를 활용
- MIDI 파일에서 템포, 화성, 리듬, 멜로디 등의 특징을 추출
- music21 라이브러리를 사용하여 MIDI 파일 분석

#### MIDI 벡터화 모듈 (MIDIVectorizer)
- 기존 코드의 `MIDIVectorizer` 클래스를 활용
- 추출된 MIDI 특징을 벡터로 변환
- LangChain의 임베딩 모델과 FAISS 벡터 저장소 활용

#### 벡터 데이터베이스
- FAISS를 사용하여 MIDI 특징 벡터를 저장하고 검색
- 유사도 검색을 통해 입력 MIDI와 유사한 MIDI 파일 검색

### 2.2 MCP(Model Context Protocol) 통합 계층

#### MCP 서버
- MIDI 데이터 소스와 AI 모델 간의 연결을 위한 MCP 서버 구현
- 벡터 데이터베이스와 상호작용하여 관련 MIDI 데이터 검색
- 클라이언트 요청에 따라 적절한 컨텍스트 제공

#### MCP 클라이언트
- AI 모델이 MCP 서버와 통신하기 위한 클라이언트 구현
- 사용자 요청을 MCP 서버로 전달하고 응답 처리

### 2.3 LLM 및 생성 계층

#### LLM API 모듈
- 기존 코드의 `LLMAPI` 클래스를 확장
- LangChain을 활용하여 LLM과 통합
- 프롬프트 엔지니어링 및 응답 처리 로직 구현

#### YuE 음악 생성 모듈
- YuE 오픈소스 모델을 활용한 음악 생성 기능 구현
- MIDI 특징을 기반으로 새로운 음악 생성
- 생성된 음악의 보컬 및 반주 트랙 처리

### 2.4 API 및 인터페이스 계층

#### FastAPI 웹 서버
- FastAPI를 사용하여 RESTful API 구현
- 비동기 처리를 통한 고성능 API 서버
- 자동 API 문서 생성 및 데이터 검증

#### 엔드포인트 정의
- `/train`: MIDI 파일을 학습하고 벡터 저장소 생성
- `/generate`: 입력 MIDI를 기반으로 새로운 MIDI 생성
- `/vectorstore`: 벡터 저장소 관리 (저장, 로드)

## 3. 데이터 흐름

### 3.1 학습 과정
1. 사용자가 학습용 MIDI 파일 제공
2. MIDIFeatureExtractor가 MIDI 파일에서 특징 추출
3. MIDIVectorizer가 추출된 특징을 벡터로 변환
4. 벡터 데이터베이스에 벡터 저장
5. 학습 완료 상태 반환

### 3.2 생성 과정
1. 사용자가 입력 MIDI 파일 제공
2. MIDIFeatureExtractor가 입력 MIDI에서 특징 추출
3. MCP 서버가 벡터 데이터베이스에서 유사한 MIDI 검색
4. LLM API가 입력 특징과 유사 특징을 기반으로 새로운 MIDI 생성 요청
5. YuE 모델이 새로운 음악 생성
6. 생성된 MIDI 파일 반환

## 5. 기술 스택 통합 방안

### 5.1 MCP와 LangChain 통합

- 컨텍스트 관리 및 메모리 기능 활용

### 5.2 FastAPI와 YuE 통합

- 생성된 음악 파일의 스트리밍 및 다운로드 기능 제공
