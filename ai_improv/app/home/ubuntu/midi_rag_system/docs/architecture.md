# MIDI RAG 시스템 아키텍처 문서

## 1. 시스템 개요

MIDI RAG(Retrieval-Augmented Generation) 시스템은 MCP, LangChain, FastAPI, YuE를 통합하여 MIDI 파일을 기반으로 한 AI 즉흥 연주 프로그램을 구현합니다. 이 시스템은 사용자가 입력한 MIDI 파일과 유사한 특성을 가진 MIDI 파일을 검색하고, 이를 기반으로 새로운 MIDI 음악을 생성합니다.

## 3. 구성 요소 설명

### 3.1 데이터 처리 및 저장 계층

#### MIDI 특징 추출기 (MIDIFeatureExtractor)
- **역할**: MIDI 파일에서 템포, 화성, 리듬, 멜로디 등의 특징을 추출
- **구현**: `midi_feature_extractor.py`
- **주요 기능**:
  - MIDI 파일 파싱 및 분석
  - 템포, 화성, 리듬, 멜로디 특징 추출
  - 키 시그니처, 타임 시그니처, 악기 정보 추출
- **의존성**: music21 라이브러리

#### MIDI 벡터화 모듈 (MIDIVectorizer)
- **역할**: 추출된 MIDI 특징을 벡터로 변환하고 벡터 저장소 관리
- **구현**: `midi_vectorizer.py`
- **주요 기능**:
  - MIDI 특징을 Document 객체로 변환
  - 임베딩 모델을 사용하여 특징 벡터화
  - FAISS 벡터 저장소 생성, 저장, 로드
- **의존성**: LangChain, FAISS, Ollama 임베딩

#### 벡터 데이터베이스
- **역할**: MIDI 특징 벡터를 저장하고 유사도 검색 제공
- **구현**: FAISS 벡터 저장소
- **주요 기능**:
  - 고차원 벡터의 효율적인 저장
  - 유사도 기반 빠른 검색
  - 로컬 파일 시스템에 저장 및 로드

### 3.2 MCP(Model Context Protocol) 통합 계층

#### MCP 서버
- **역할**: MIDI 데이터 소스와 AI 모델 간의 연결을 위한 서버
- **구현**: `mcp_server.py`
- **주요 기능**:
  - MIDI 검색 엔드포인트 제공
  - MIDI 파일 목록 조회 엔드포인트 제공
  - MIDI 특징 조회 엔드포인트 제공
- **의존성**: MCP Python 라이브러리

#### MCP 클라이언트
- **역할**: AI 모델이 MCP 서버와 통신하기 위한 클라이언트
- **구현**: `mcp_client.py`
- **주요 기능**:
  - MIDI 검색 요청
  - MIDI 파일 목록 요청
  - MIDI 특징 조회 요청
- **의존성**: MCP Python 라이브러리

### 3.3 LLM 및 생성 계층

#### LLM API 모듈
- **역할**: LangChain을 활용하여 LLM과 통합하고 MIDI 생성을 위한 프롬프트 처리
- **구현**: `llm_api.py`
- **주요 기능**:
  - LLM 프롬프트 템플릿 관리
  - LLM 응답 정제 및 처리
  - 생성된 솔로 확장 및 개선
- **의존성**: LangChain, Ollama LLM

#### YuE 음악 생성 모듈
- **역할**: YuE 오픈소스 모델을 활용한 음악 생성
- **구현**: `yue_generator.py`
- **주요 기능**:
  - YuE 모델 로드 및 관리
  - 장르 및 가사 기반 음악 생성
  - JSON 형식의 MIDI 데이터를 실제 MIDI 파일로 변환
- **의존성**: Transformers, PyTorch, Mido

### 3.4 API 및 인터페이스 계층

#### FastAPI 웹 서버
- **역할**: RESTful API 제공
- **구현**: `server.py`
- **주요 기능**:
  - 파일 업로드/다운로드 엔드포인트
  - 학습 및 생성 엔드포인트
  - 파일 목록 조회 엔드포인트
- **의존성**: FastAPI, Uvicorn

#### MIDI RAG 시스템 메인 모듈
- **역할**: 모든 구성 요소를 통합하는 메인 시스템
- **구현**: `midi_rag_system.py`
- **주요 기능**:
  - 시스템 초기화 및 구성
  - 학습 및 벡터 저장소 관리
  - MIDI 생성 워크플로우 조정
- **의존성**: 모든 구성 요소

## 4. 데이터 흐름

### 4.1 학습 과정
1. 사용자가 학습용 MIDI 파일을 업로드 (`/upload/training` 엔드포인트)
2. 사용자가 학습 요청 (`/train` 엔드포인트)
3. MIDI 특징 추출기가 각 MIDI 파일에서 특징 추출
4. MIDI 벡터화 모듈이 추출된 특징을 벡터로 변환
5. 벡터 데이터베이스에 벡터 저장
6. 학습 완료 상태 반환

### 4.2 생성 과정
1. 사용자가 입력 MIDI 파일을 업로드 (`/upload/input` 엔드포인트)
2. 사용자가 생성 요청 (`/generate/{input_file}` 엔드포인트)
3. MIDI 특징 추출기가 입력 MIDI에서 특징 추출
4. MCP 활성화 시:
   - MCP 클라이언트가 MCP 서버에 유사한 MIDI 검색 요청
   - MCP 서버가 벡터 데이터베이스에서 유사한 MIDI 검색
   - MCP 서버가 검색 결과 반환
5. MCP 비활성화 시:
   - 벡터 데이터베이스에서 직접 유사한 MIDI 검색
6. LLM API가 입력 특징과 유사 특징을 기반으로 프롬프트 생성
7. YuE 모델이 새로운 음악 생성
8. 생성된 MIDI 파일 저장 및 결과 반환

## 5. 기술 스택 통합

### 5.1 MCP와 LangChain 통합
- MCP 서버는 LangChain의 벡터 저장소와 통합되어 MIDI 데이터 검색 제공
- MCP 클라이언트는 LLM API 모듈과 통합되어 컨텍스트 기반 생성 지원
- LangChain의 Document 객체를 사용하여 MIDI 특징 표현

### 5.2 FastAPI와 YuE 통합
- FastAPI 엔드포인트가 YuE 모델 호출을 조정
- 비동기 처리를 통한 효율적인 음악 생성 요청 처리
- 백그라운드 작업을 통한 장시간 실행 작업 관리

### 5.3 전체 시스템 통합
- 모듈화된 설계로 각 구성 요소 독립적 테스트 및 개발 가능
- 중앙 설정 파일(`config.py`)을 통한 시스템 구성 관리
- 비동기 프로그래밍을 통한 효율적인 리소스 사용
